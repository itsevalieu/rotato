## Summary

- 6 interchangeable project form layouts: Classic, Sentence, Seed Packet, Two-Beat, Envelope, Live Preview
- Style preference persists in GardenState via idb-keyval (survives tab refresh)
- Switching styles mid-form preserves all entered field values
- `FormStylePicker` in modal header (ADR-005 `headerAction` slot)
- Live Preview: real-time mini card preview updates on every keystroke
- Two-Beat: two-step form with Framer Motion step transition

## How to test

1. Open project form — style picker visible in header
2. Enter a title, switch styles — title preserved
3. Close and reopen modal — last used style restored
4. Reload page — style still active

6. Live Preview: type in any field — preview card updates immediately
7. Two-Beat: enter title, click Next — Step 2 slides in
