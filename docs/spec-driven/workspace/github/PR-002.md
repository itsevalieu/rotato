## How to test

1. Click "New Project" — modal opens, defaults to Currently Playing
2. Submit without title — validation error, no submission
3. Fill all fields and submit — project appears on board
4. Click edit on a card — form opens pre-populated
5. Press Escape — modal closes, no changes saved
