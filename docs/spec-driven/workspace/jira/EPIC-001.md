## Description

Ship a local-first creative project tracker that helps multidisciplinary makers see all their projects at a glance without the anxiety of a task manager.

**Core constraint (from Red Team audit RT-003):** Local-first is a permanent architectural constraint. No account system. No cloud sync. Ever.

**Anti-urgency principle:** No deadline fields. No completion percentages. No red colors in the UI.

## Acceptance criteria (epic level)

- All P0 features ship in v1.0 (ROT-001, ROT-002, ROT-003)
- P1 features ship in v1.1 (ROT-004, ROT-005)
- P2 features ship in v1.2+ (ROT-006)
- Zero hydration errors in production
- Data persists across browser refresh (IndexedDB)
- Lighthouse accessibility score > 90
