## Description

As a user, I want a modal form where I can create or edit a project, choosing a color, icon, section, and tags, so my projects feel personal and organized.

## Acceptance Criteria

1. Given the board, when the user clicks "New Project", then a modal opens with an empty form defaulting to Currently Playing.
2. Given a title entered, when the user clicks Save, then the project is added and the modal closes.
3. Given no title, when the user clicks Save, then a validation message appears and the form does not submit.
4. Given an existing project card, when the user clicks Edit, then the form opens pre-populated.
5. Given the edit form, when the user saves, then changes appear immediately on the board.
6. Given any open modal, when the user presses Escape or clicks X, then the modal closes with no changes.
7. Given the color picker, when a color is selected, then the preview updates immediately.
8. Given the icon picker, when an icon is selected, then the preview updates immediately.

## Tech Lead notes

- Form state: local `useState` per field — not in GardenContext (ephemeral until submit)
- On submit: dispatch `ADD_PROJECT` or `UPDATE_PROJECT`
- Color palette: `PALETTE_COLORS` from constants; icons: `ICON_OPTIONS` from constants
- This ticket is the foundation ROT-006 builds on — keep the form component clean and composable
