## Description

As a first-time user, I want a welcoming modal that offers to show me around with sample projects, so I can understand the app without having to imagine it with empty sections.

## Acceptance Criteria

1. Given a first-time user (no `rotato-onboarding-done` in localStorage), when the app loads, then the onboarding modal appears.
2. Given the onboarding modal, when the user clicks "Show me around", then demo projects load and a dismissible banner appears.
3. Given the onboarding modal, when the user clicks "Start fresh", then the board is empty and the modal closes.
4. Given demo data active, when the user clicks "Clear demo data", then all demo projects are removed.
5. Given a returning user, when the app loads, then no onboarding modal is shown.

## Tech Lead notes

- Onboarding flag: `localStorage.getItem(ONBOARDING_KEY)` — use the constant, never hardcode the string
- Demo projects: defined in `src/lib/seed-data.ts` — do not generate inline
- `isDemoData: boolean` in GardenState controls banner visibility
- Demo clear: dispatch `CLEAR_DEMO_DATA` action
