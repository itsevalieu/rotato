## Description

As a user, I want to drag project cards to reorder them within a section and move them to a different section, so I can organize my board without using menus.

## Acceptance Criteria

1. Given a project card, when dragged within its section, then it reorders and persists on reload.
2. Given a project card, when dragged to a different section, then it moves and persists on reload.
3. Given a drag released over a valid drop zone, then the card drops without visual glitch.
4. Given a drag released outside any drop zone, then the card returns to its original position.
5. Given a drag-and-drop move between sections, then a `TimelineEntry` is added to the project's history.

## Tech Lead notes

- Library: dnd-kit (`DndContext`, `SortableContext`, `useSortable`, `useDroppable`)
- **CRITICAL — ADR-004 + ADR-006:** dnd-kit adds `aria-describedby` on client only. Wrap draggable items in mounting guard (`const [mounted, setMounted] = useState(false)`). Missing this guard = hydration mismatch in production.
- On drop: `REORDER_PROJECTS` (same section) or `MOVE_PROJECT` (different section)
- `MOVE_PROJECT` must add a `TimelineEntry` to the project
