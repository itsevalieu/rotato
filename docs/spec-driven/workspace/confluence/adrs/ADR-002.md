# ADR-002: React Context + useReducer for State Management

| Field | Value |
|---|---|
| **Status** | Accepted |
| **Date** | Stage 4 — Architecture |
| **Author** | Tech Lead |
| **Confidence** | 🟡 AMBER |

## Context

Need global state for projects, view mode, ambient settings, and form style preferences. Options:
- **React Context + useReducer** — zero dependency, readable, entire state in one place
- **Zustand** — minimal, popular, good DX
- **Redux Toolkit** — heavyweight for an app of this scale
- **Jotai** — atomic, flexible, adds dependency

## Decision

Use **React Context + useReducer**. Single `GardenContext` with `GardenState` shape and `GardenAction` union type.

## Consequences

- No additional dependency
- Entire state shape visible in `src/lib/types.ts` — single source of truth
- All mutations go through typed `GardenAction` — no direct state mutation
- Re-renders on any state change — acceptable at this scale (state updates are infrequent)
- **Enforce via `architecture.mdc` rule:** no Zustand, Redux, or Jotai imports allowed

## Confidence note

🟡 AMBER — reasonable default for an app of this scale. Not explicitly spec'd. Would revisit if state complexity grows significantly.
