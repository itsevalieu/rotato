# ADR-001: Next.js App Router

| Field | Value |
|---|---|
| **Status** | Accepted |
| **Date** | Stage 4 — Architecture |
| **Author** | Tech Lead |

## Context

Need a React framework with good DX, SSR support, and a straightforward Vercel deploy story. App is client-only at runtime but benefits from SSR for initial load performance and SEO on the landing page.

Options considered:
- **Next.js App Router** — modern, Vercel-native, server components available
- **Next.js Pages Router** — stable but moving toward legacy status
- **Vite + React SPA** — simpler, no SSR, pure client bundle

## Decision

Use **Next.js App Router**.

## Consequences

- Server components available but not heavily used — app is effectively client-only after hydration
- SSR behavior requires explicit handling of client-only APIs (`Date.now()`, `localStorage`, `toLocaleString()`) — see ADR-006
- dnd-kit attributes are client-only and require mounting guards — see ADR-006
- Static export possible (`output: 'export'`) for hosting outside Vercel
