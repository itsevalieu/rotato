# ADR-005: Modal `size` and `headerAction` Props

| Field | Value |
|---|---|
| **Status** | Accepted |
| **Date** | Red Team Gate 2 — after design spec complete |
| **Author** | Tech Lead |
| **Confidence** | 🟢 GREEN |

## Context

Surfaced during **Red Team Gate 2** when the design spec was reviewed against the PRD. Two design requirements were not addressable by the original `Modal` component:

1. `LivePreviewForm` requires a wider modal than the default — the two-column layout needs more horizontal space
2. `FormStylePicker` needs to render in the modal header alongside the title — no slot existed for this

## Decision

Add two optional props to `Modal.tsx`:
- `size?: "md" | "lg"` — controls max-width (`md`: default, `lg`: wider for split-panel layouts)
- `headerAction?: ReactNode` — renders between the title and close button; used for `FormStylePicker`

## Consequences

- Modal is more composable for future feature variations
- `headerAction` slot is a general-purpose escape hatch — document intended uses to avoid misuse
- `size="lg"` is passed by `ProjectForm` when `formStyle === "live-preview"`, default otherwise
- No breaking change — both props are optional with backward-compatible defaults
